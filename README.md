# Пиксель: остров слов

Браузерное приключение для подготовки к словарному диктанту. Игрок бегает по островам, прыгает через воду на платформы, собирает монеты, выполняет задания и покупает костюмы, питомцев и украшения для своего дома.

## Запуск и публикация

Откройте `index.html` в современном браузере. Для телефона удобнее открыть опубликованную ссылку.

Для GitHub Pages:

1. Загрузите `index.html` в корень репозитория.
2. В **Settings → Pages** выберите **Deploy from a branch**, ветку с файлом и папку **/ (root)**.
3. Сохраните настройки и откройте ссылку после публикации.

Игра состоит из одного HTML-файла. Нет сборки, зависимостей, внешних изображений, сетевых библиотек, рекламы или регистрации. Прогресс хранится в localStorage в этом браузере и не переносится между устройствами. Браузер покажет сообщение, если сохранение недоступно.

## Управление

- **Телефон:** джойстик слева, прыжок справа, доступное действие по центру.
- **Компьютер:** WASD / стрелки, пробел — прыжок, E — действие.
- Можно нажать на землю, чтобы идти к выбранной точке. Автоматического обхода препятствий нет.
- Рядом с Пикселем, магазином, мостом или сундуком внизу по центру появляется кнопка доступного действия. При отходе она исчезает.
- Когда появляются буквенные плиты, центральная кнопка меняется на «Выбрать». Она становится активной, когда герой встаёт на плиту. Во время задания кнопка «Задание» не появляется.

## Мир и покупки

- Основной остров: площадь, Пиксель, магазин и дом игрока.
- На карте 21 остановка с отдельными названиями и значками: 8 на основном острове, 8 в саду и 5 у Башни.
- На каждой остановке ровно одно задание, затем цель переходит дальше. В карточке показана следующая остановка, а указатель ведёт через мосты. При появлении плит соседние значки временно скрываются, чтобы не закрывать буквы.
- После 8 пройденных остановок можно открыть мост в Сад букв; после 16 — дорогу к Башне. Ответ с подсказкой тоже позволяет двигаться дальше. Ранее открытые мосты остаются открытыми.
- В воде есть платформы с кристаллами и сундуком. Прыжок позволяет перескакивать между ними. При падении игрок возвращается на берег без потери монет.
- В саду патрулирует слизень; его можно перепрыгнуть.
- Кристаллы и сундук собираются один раз. Задания повторяются на следующем круге маршрута и дают монеты для покупок. Персонаж не переносится к другой площадке при начале задания.
- Купленные костюмы и питомцы сразу становятся активными; в магазине можно выбрать другой уже купленный предмет. У костюмов разные детали: комбинезон с рюкзаком, лисье худи, платье со звёздами. В магазине показан их настоящий вид.
- Цветы и крупный фонтан с анимацией воды появляются у домика, корона — на герое. Прежние покупки и этапы слов сохраняются; новый маршрут начинается с первой остановки.

## Как учатся слова

В игре все 21 слово с карточки. Под № 19 сохранена форма «запечатлел».

Для каждого слова три этапа:

1. **Плиты букв.** Одно трудное место спрятано; нужно добежать до плиты с правильной буквой или сочетанием букв. Награда — 8 монет.
2. **Мастерская слов.** По смысловой подсказке собрать полное слово из перемешанных букв. Награда — 10 монет.
3. **Заклинание памяти.** Написать полное слово по смысловой подсказке без образца. Награда — 14 монет.

Каждой остановке соответствует одно слово. После завершения задания нужно бежать к следующей; повторная практика этого слова будет на следующем круге. На новом круге вид задания определяется сохранённым этапом слова: пропуск, сборка или письмо по памяти.

При ошибке показываются правильное написание и пояснение. После ошибки или открытой подсказки выдаётся только 2 монеты за завершение, а уровень слова не растёт, но переход к следующей остановке остаётся доступен. Если в уже пройденном задании на письмо по памяти допущена ошибка, слово снова требует самостоятельного написания.

Подсказку в сборке и письме по памяти можно открывать и закрывать той же кнопкой; набранный ответ сохраняется. Закрытие подсказки не отменяет отметку о помощи в текущем задании.

Отметка «по памяти» означает один самостоятельный правильный ответ целиком; это не гарантия усвоения или школьной оценки. За пару дней до диктанта лучше несколько коротких заходов с перерывами. Перед диктантом проверьте слова письменно на бумаге.

Кнопка книги открывает коллекцию и текущие этапы. Справка **?** содержит управление, пояснения для взрослого и сброс прогресса с подтверждением.
